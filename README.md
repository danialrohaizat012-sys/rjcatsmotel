# Demo Sistem RJ Cat Motel & Spa

Demo cadangan sistem pengurusan oleh **Binalab** untuk RJ Cat Motel & Spa, Kota Bharu.

Semua data dalam demo ialah data contoh. Bayaran (FPX, DuitNow) dan mesej WhatsApp hanya simulasi.

## Cara guna

Buka `index.html` dalam browser, atau layari versi GitHub Pages.

- **Paparan Pelanggan**: tempah hotel kucing (semakan bilik kosong secara langsung) atau slot grooming, kemudian bayar deposit.
- **Paparan Staf**: papan pemuka, kalendar bilik, jadual grooming, profil kucing, kaunter jualan (POS) dan laporan.

Cadangan demo: buat satu tempahan di Paparan Pelanggan, kemudian tekan "Lihat di Paparan Staf" untuk lihat tempahan itu muncul terus.

Data kembali asal setiap kali halaman dimuat semula.
